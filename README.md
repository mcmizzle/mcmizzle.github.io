Serves [mcmizzle.com](https://mcmizzle.com) via GitHub Pages.

**Generated — don't edit here.** Every file in this repo except this README is
copied in by CI from a separate source repository whenever that repository
changes. An edit made here is overwritten on the next sync, and a file added
here is deleted by it.

This README is the deliberate exception: the sync preserves it, so it is the
only file in this repo that is safe to change. Everything else, including the
site's content, `robots.txt`, `sitemap.xml` and `CNAME`, is written from
source.

Issues and pull requests belong on the source repository rather than here,
which is why both are disabled.
